# Skyrim Lovense - Interface
Code related to the UI used to connect and view toys to Skyrim. The main project can be found [here](https://github.com/KrisV-777/Skyrim-Lovense/tree/main).  
You need Flash Professional CS6 to work on this code.

## Layout
The Menu uses 2 input fields which allow setting IP address and port used to connect to toys, these are forwarded to the backend. Below is a list of currently connected items which can be interacted with to set the body location they interact
with (a feature that can be used by authors to create a more responsive/immersive experience).
Detailed usage instructions are found on the [Nexus Mods page](https://www.nexusmods.com/skyrimspecialedition/mods/133698).
